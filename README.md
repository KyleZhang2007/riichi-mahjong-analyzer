# Riichi Mahjong Analyzer
A work-in-progress Riichi Mahjong analysis engine built primarily in C++.
## Overview
The aim is to create an anylzer that recommends optimal discards not just based on the player's hands, but also based on the curent game state (turn #, opponent discards, etc).
## Features
Nothing

Working on:
- Tile representation
- Winning hand detection
- Shanten Calculation
- Ukuire Calculation
Planned:
- Discard based on tile efficiency
- Yaku recognition and scoring
- Expected Value Calculation
- Tenpai %

- MJAI compatibility for log parsing

- Computer Vision for online
- Video analysis
